# Four-Site Holstein With Ito Coherent-State Walkers

This example runs the real-space four-site Holstein model using the current
bare `EulerItoPropagator`.

The default run is:

- 4 sites, periodic boundary conditions
- one electron, `K = 0` Toyozawa coherent-state trial
- `t = 1`, `g = 1`, `w0 = 1`
- 200 total walkers
- timestep `0.005`
- 20 blocks with 1 Euler-Maruyama step per block
- population control every step

This is intentionally a diagnostic example. The propagator is the first bare
Euler-Maruyama implementation: it uses proper complex noise and the normalized
coherent-state gauge factor, but it does not yet include force bias, drifted
complex noise, or the later semi-exact splitting.

Run the smoke test:

```bash
conda run -n ipie_dev python -m pytest test_holstein_ito_workflow.py
```

Run AFQMC:

```bash
conda run -n ipie_dev python run_afqmc.py
```

Use the optimized Toyozawa trial generated by example 23:

```bash
conda run -n ipie_dev python run_afqmc.py --trial-file ../23-holstein_cs_walkers_4site/optimized_toyozawa_trial.npz
```

The default outputs are `estimates.0.h5`, `energy.dat`, and the line-flushed
stdout log `afqmc.out`.
